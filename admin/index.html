1. Conexao com o GitHub

Crie em GitHub → Settings → Developer settings → Personal access tokens (fine-grained), com permissao Contents: Read and write somente neste repositorio. O token fica salvo apenas no seu navegador (localStorage) e e enviado direto para a API do GitHub — nunca passa por nenhum outro servidor.
